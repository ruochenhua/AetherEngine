## Implementation summary

- Added validated `TimeMode`, `TimeControl`, `TimeSample`, and `FrameTime` contracts.
- Added deterministic WallClock, FixedStep, and Seek sample generation with bounded replay and normalized seek targets.
- Added a generic checkpointable `DeterministicSystem` seam with atomic reset/step/dispatch rollback and typed stage/step errors. This is the documented T5/T6/T7 integration point; no physics, particle, or animation runtime was added.
- Added typed launcher parsing for explicit/implicit time modes, compatibility `--freeze-time`, duplicate/conflict handling, finite/range checks, and seek limits while preserving existing valid flags.
- Added strict serde VisualCase v2 parsing, required/unknown field rejection, IDs, project-relative paths, numeric/time/camera/compare/reference validation, pending versus releasable provenance, and explicit variant materialization.
- Kept `tests/visual-matrix.json` at its existing v1 boundary because no T0.2 runner was introduced; no permissive v1/v2 parser was added.
