## Scope and resolved review findings

Read `.superpowers/sdd/t0.1-brief.md`, `.superpowers/sdd/t0.1-review.md`, and
`docs/engineering-governance.md` completely. Checked the frozen roadmap schema
in section 4.6.10.b and its structured expectation examples without editing it.

1. VisualCase v2 now accepts exactly `Render` / `ExpectedError`, with typed
   diagnostic severity, fallback scope/mode, metric operators, hashes, all six
   probe kinds, and graph read/write lists plus ordered edges. Added strict
   benchmark/device/paired types and `benchmark_override`. Unknown fields and
   missing required nullable fields remain rejected. Frozen unpaired benchmark
   literals may omit `paired`.
2. `materialize()` returns complete `MaterializedCase` records with preserved
   typed expectations and applied launcher/time/camera/benchmark overrides.
   Each child gets `tests/reference/<base>__<variant>.png` and fresh pending
   provenance, never the base image's certification. `artifacts(run_id)` derives
   distinct output/diff/report paths. No files are captured or promoted.
3. `from_json_in(input, project_root)` checks canonical containment, rejects
   symlink escapes, dangling links, cycles, missing scenes, missing roots, and
   unresolved parents. A pending reference may have an absent final filename
   only when its parent resolves inside the allowed root. A reference with
   complete provenance must exist. Materialization rechecks child paths and
   the current filesystem.
4. WallClock uses a finite f64 sum/quotient and modulo remainder, caps dispatch
   before integer conversion, and discards excess catch-up. Tests cover repeated
   `f32::MAX`, `1e30`, subnormal fixed steps, caps 1/3/8, and following zero-delta
   frames with no retained whole steps.
5. Seek construction stores the normalized time and step index immediately.
   Publication remains empty until dispatch. Tests cover targets just inside
   and outside tolerance and exactly 4096 versus 4097 steps.
6. Rollback tests assert stage, exact step index, original cause, and unchanged
   control/system/publication state for reset/step/dispatch and rejected calls.
   Nested schema tests remove required fields, inject unknown fields, and
   exercise invalid camera, expectation, benchmark, and time values.
7. Restored the original architecture overview verbatim. Only the two T0.1
   module exports are added relative to the original module list. Removed two
   blank separator lines and redundant export comments to retain the existing
   22-line module-health baseline without changing that baseline.
