# T0.2 implementation report

## Scope

T0.2 adds a serial, single-coordinator process runner for the existing visual
regression shell flow. It binds each launcher to a verified POSIX process
group, waits for an opt-in first-frame handshake, captures diagnostics, and
cleans descendants before the next case. It does not change renderer output,
reference images, comparison thresholds, or the visual matrix schema.

## Changes

- Added `scripts/process_lease.py` with nonce-bound identity validation,
  process-group signalling, TERM/KILL escalation, and state transitions.
- Added `scripts/runner_process.py` with serial manifest execution, exact argv
  construction, handshake/case deadlines, per-case stdout/stderr/log files,
  and cancellation cleanup.
- Added `AETHER_READY_FD` support to the launcher; the byte is emitted once
  after the first successful presentation and is disabled when absent.
- Updated `scripts/verify-regression.sh` and the Metal wrapper to use one
  coordinator without recursive Terminal invocation.
- Added bounded fake-process tests and static shell checks; no real launcher,
  Metal session, or screenshot matrix was used.

## Crash diagnosis and fix

The supplied macOS crash report was not an engine or Metal crash. The fake
launcher test contained `os.kill(os.getpid(), SIGABRT)` to model a signal exit.
That intentionally aborted a Python test child and caused macOS to create the
crash report. It now uses `sys.exit(134)`, preserving non-zero-exit coverage
without invoking the OS crash reporter.
