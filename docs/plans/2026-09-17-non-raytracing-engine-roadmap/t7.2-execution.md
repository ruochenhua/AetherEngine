# T7.2 execution checkpoint

Date: 2026-10-03

## Implemented

- Extract immutable CPU poses against a pinned scene generation and primitive snapshot.
- Build a 128-entry column-major GPU palette and upload it through a read-only storage-buffer binding.
- Preserve non-joint ancestor transforms and use `global_joint * inverse_bind` for palette matrices.
- Calculate animated world bounds using the same weighted palette as the vertex shader.
- Fall back per primitive for unsupported joint counts, invalid pose data, missing skin streams, and out-of-range influences.
- Add typed glTF `SkeletonAsset` and `AnimationClipAsset` derivation from an owned `GltfDocumentAsset`.
- Sample Step/Linear TRS channels, use quaternion slerp for rotations, and expose deterministic seek/play/pause/speed/loop controls through `AnimatorState`.
- Lock SHA-256 `pose_state` values at 0, 0.25, 0.5, and 0.75 seconds in an engine test.
- Load `tests/fixtures/t7_animated_actor.gltf`, run its `RaiseArms` clip through `AnimationFrame` extraction, and create skinned GPU render batches from the resulting palettes.
- Feed those batches to GBuffer, Shadow, and WaterReflection. The screenshot runner captures one frame and then exits.
- Add an Inspector Animation section with play/pause, time seek, speed/reverse, and loop controls. Wall-clock and fixed-step modes advance playback; seek/freeze modes keep deterministic poses.
