# T9.4 遮挡与地形流送研究执行记录

日期：2026-10-04
范围：仅 RFC 和 research-only 原型；不进入 launcher、RenderGraph 或 release gate。

## 结论

- 研究工件门：**PASS**。离屏 GPU 原型、CPU/GPU 一致性检查、可复跑报告和 RFC 均已生成。
- 遮挡：在固定的 48×27 tile、8 个矩形遮挡体、10,000 个候选合成工作负载中，本机 Intel Iris Xe / Vulkan 的两阶段 compute GPU 时间为 **p50 0.02641 ms / p95 0.03333 ms**。30 warm-up 后采集 120 个有效样本；CPU 与 GPU 可见 mask **0 处不一致**，合成候选数减少 **33.0%**。
- 内存：原型已知 wgpu buffer footprint 为 **170,144 bytes**。该值不包括 driver-managed query set、pipeline、分配器开销和任何引擎场景资源。
- 地形流送：128×128 个 64 KiB chunk、7×7 活动窗口、12 步路线的模型峰值驻留载荷为 **3,211,264 bytes**，相对 eager payload 估算下降 **99.69%**。这是计数模型，不是引擎 allocator、磁盘 I/O 或 GPU 上传实测；这些耗时保留为 unavailable/null。
- 生产决定：**NO-GO**。合成 tile workload 不能证明真实场景的图像正确性、draw-call 收益或端到端帧时；streaming 的 I/O、接缝和 GPU 上传尚未测量。

## 开关与边界

示例默认关闭，需要显式 `--prototype-enabled` 才会运行；未注册到 launcher、生产 RenderGraph 或 release gate。停止这个独立进程即可关闭实验。

已知遮挡风险：半透明物体、细薄遮挡体、深度反转、相机近裁面和 tile 边界导致误剔除。已知流送风险：快速移动造成空环、磁盘抖动、地形接缝、LOD 不连续和 chunk payload 异构造成的内存偏差。

下一阶段只有在另行批准引擎集成计划，并具备真实场景视觉等价检查、同设备 paired GPU 基线、allocator/上传测量与相机运动覆盖后，才考虑 production implementation。
