统一交付规则

  • 每个任务包只运行自己的专项测试和 primary case；共享 RenderGraph、资源生命周期或 pipeline ABI 改动才扩大矩阵。
  • 所有报告使用 HTML；需要截图时报告必须同时保留 reference、output、diff、graph/metrics dump 和日志。
  • 失败必须进入 blocked/needs-review 并保留产物，禁止通过改阈值、删除 case 或覆盖 reference 来制造通过。
  • 进入编码前仍以完整规范中的 SliceExitContract 为最终字段合同。
