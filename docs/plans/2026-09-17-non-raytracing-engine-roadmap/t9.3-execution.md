# T9.3 配对 Instancing 执行记录

## 验收边界

- 固定 10,000 实体场景，seed 9003，1280×720，同一 scene、camera、time、设备。
- baseline 关闭 instancing，feature 开启 instancing；两组均开启 visibility、关闭 LOD。
- 每组 30 帧 warm-up、120 个有效样本，launcher 在第 150 帧后自动退出。
- 同时比较 device_key、pair_key、解码 RGBA8、visible entity 和 editor-visible state；逐帧 visible/culled 计数必须一致。
- baseline draw-call p50 必须大于 0，feature 至少减少 30%；任一条件失败就保持关闭路径。

## 可复现入口

运行 `./scripts/run-slice-tests.sh --slice T9.3`。入口先执行 extraction 顺序、state hash 和报告合同测试，再构建 Release launcher，生成同一份 scene 并连续采集 off/on。完整结果位于 `tests/reports/<run-id>/t9_instancing_paired_10k/report.html`，逐帧差异和放行决定位于 `paired-delta.json`。

报告附带 baseline/feature 截图、case、benchmark series、visibility sidecar、构建日志和 launcher 输出。截图通过限帧 launcher 生成，不保留测试窗口。
