目标与范围

收益：每个 case 都能串行、无 GUI、可清理、可复现，并生成可审计 HTML。

不做：不并发启动全量矩阵；不为 case 打开 Terminal；runner 不持有 Metal。

技术设计

VisualCase 与报告

VisualCase v2 把 primary/variant materialize 成独立 case，保留 argv、provenance、graph、metrics、reference/output/diff。

进程租约

单 runner、单 launcher child、单 Metal session。Reserved→Bound→Ready→Terminating→Cleaned，绑定 pid/start-time/pgid/nonce，由 supervisor 清理。

TimeControl

T0.1 负责 CLI/parser、FixedStep/Seek、checkpoint/restore 和 rejected-call invariant；T5/T6/T7 只接入各自系统。

接口与任务

  • VisualCaseV2、SliceExitContract 是 schema seam。
  • ProcessGroupLease 的终止能力只属于 supervisor。
  • TimeControl 失败必须恢复 simulation checkpoint。
