# 编辑器操作交互合同（提案）

状态：首轮实现已通过 CI 与编辑器实屏验证；真实触控板手测待完成
日期：2026-10-18
范围：场景视口导航、编辑/运行模式输入、视口操作 Tips

本文件把实现前基线、已实现行为与后续验证项分开记录。触控板的副键拖动、滚动方向和捏合手感仍需真实设备确认。

## 目标

- 新用户能在视口内直接发现选择、导航和聚焦操作，不必先查文档。
- 鼠标与 Mac 触控板都有可用的视角操作路径；不要求触控板用户必须拥有中键。
- 场景选择、操纵器、相机导航和 Play 输入各自有明确的事件所有者。
- 按键/手势未被视口接收时不得偷偷移动编辑器相机；取消导航后不残留按键状态。
- Tips 只列出当前模式和设备实际可用的功能。

## 首轮实现记录（2026-10-20）

- 已接入右键按住后的鼠标观察/飞行与指针捕获、中键平移、滚轮推近/拉远、右键滚轮调速、Shift+滚动垂直平移、Option/Alt+左键绕所选对象旋转、F 聚焦所选对象。
- 窗口失焦、Esc 和右键释放会退出捕获并清理输入状态；egui 消费的滚动不会延迟泄漏到视口。
- winit 0.30 的 macOS `PinchGesture` 已接入相机推近/拉远；Tips 可切换鼠标/触控板、折叠/展开，偏好仅保留在当前会话。
- Tips 已在 macOS 编辑器窗口实屏验证。当前界面字体缺少中文及部分修饰键符号字形，因此 Tips 使用英文和 ASCII 按键名，避免显示方框；鼠标/触控板切换及折叠重开也由 launcher UI 测试覆盖。
- 带 `--screenshot` 的离屏截图仅含 3D 渲染，不含 egui UI；本次界面证据来自运行中的编辑器窗口。真实 Mac 触控板的副键拖动、滚动方向、捏合手感及系统指针捕获仍待实机手测。
- 当前编辑器没有全局 Play 模式；Tips 只展示当前 Edit 操作，不展示粒子预览的 Play/Pause/Stop 控件。

## 实现前基线（2026-10-18 代码审计）

| 操作 | 当前行为 |
|---|---|
| 左键 | 选择实体、操作操纵器 |
| Option/Alt + 左键拖动 | 相机原地旋转；不是围绕选中对象轨道旋转 |
| WASD/QE | 相机移动，不要求按住右键 |
| 滚轮 | 调整飞行速度，不是推近/拉远 |
| 中键拖动、F 聚焦、右键导航 | 未实现 |
| Play | 编辑器和 Play 共用相机输入更新；需先明确 Play 输入所有权 |

当前输入层还需要显式处理视口焦点、鼠标捕获/释放和窗口失焦时清理按键状态。当前 Project 资产拖放、场景选择、操纵器和导航之间也需要一致的优先级规则。

## 建议的桌面鼠标操作

| 用户动作 | 建议结果 | 说明 |
|---|---|---|
| 左键单击 | 选择实体 | 保留当前习惯 |
| 左键拖动操纵器 | 变换实体 | 仅在命中操纵器时开始 |
| 右键按住并拖动 | 自由观察视角 | 右键按住期间捕获视口指针；松开立即退出导航 |
| 右键按住 + WASD/QE | 飞行移动 | 仅当视口拥有输入、右键导航激活且处于 Edit 模式 |
| 右键按住 + 滚轮 | 调整飞行速度 | 与普通滚轮推近/拉远分开 |
| 中键拖动 | 平移视口 | 不改变实体选择 |
| 滚轮 | 沿视线推近/拉远 | 在正交相机使用等效缩放；右键导航时可改为调飞行速度，需在 Tips 标明 |
| F | 聚焦所选实体 | 首轮用 Transform 的最大缩放估算距离；无选择时不移动相机 |
| Option/Alt + 左键拖动 | 围绕焦点轨道旋转 | 只有实现稳定焦点枢轴后才开放；不能复用当前原地旋转并称为轨道 |
| Esc | 退出相机捕获/导航 | 不退出 Play；Play 的停止操作需独立入口 |

相机导航按住键只在视口焦点范围内生效。导航激活优先于选择和操纵器命中；释放鼠标键、按 Esc、窗口失焦、切换模式时都清理相机导航状态。UI overlay、Project、Inspector 等区域不得启动视口导航。

## 建议的 Mac 触控板操作

UE 官方把 Magic Trackpad 的「两指按压并拖动」映射为右键拖动，也把表面滚动映射为相机前后移动。macOS 本身提供两指副键点击、两指滚动和捏合缩放。参考这些惯例后，Aether 的建议如下：

| 手势 | 建议结果 | 实现前提 |
|---|---|---|
| 单指点击 | 选择实体/操纵器 | 现有左键语义 |
| 两指按压并拖动 | 观察视角 | 系统/窗口层需向应用发送可持续的副键拖动事件；真实 Mac 验证 |
| 两指滚动 | 推近/拉远 | 视口获得滚轮事件；滚动方向遵循 macOS 自然滚动设置 |
| Shift + 两指滚动 | 平移视口 | 作为没有中键时的平移入口，验证 Shift 不与 macOS 或全局快捷键冲突 |
| 捏合 | 连续缩放/推拉 | 仅在 winit/egui 当前版本确实暴露 magnify 事件并通过实机验证后启用；未验证前不展示 |
| 触控板副键点击+拖动不顺手时 | 提供显式「视角」切换按钮/键盘替代入口 | 不把持续按压作为唯一可用路径 |

两指按压拖动是 UE 的官方映射，但不应成为唯一触控板操作。Mac 触控板通常没有物理中键，因此平移必须有 Shift+滚动或可发现的 UI/键盘替代入口。我们尚未验证 Aether 当前窗口事件链能否可靠区分触控板捏合；设计稿不把捏合标成已支持。

## 编辑模式与运行模式

### Edit

- 左键选择和操纵器编辑场景。
- 鼠标/触控板导航控制编辑器相机。
- Play 启动后，场景变换输入停止；导航与游戏输入由明确的 Play 策略接管。

### Play（待确认的推荐行为）

- Play 获得游戏输入焦点，默认不执行编辑器选择、操纵器和编辑器相机快捷键。
- 鼠标是否捕获由游戏/当前场景明确请求；未捕获时保留桌面指针，Esc 先释放捕获。
- Editor 的 Tips 自动换成 Play 操作说明；没有游戏绑定信息时显示“游戏输入由当前场景控制”，不展示 Edit 相机手势。
- Stop 只停止运行并回到 Edit；不复用 Esc 作为唯一停止方式。

这解决了当前 Edit/Play 共用 `app.camera` 输入更新造成的所有权歧义；具体 Play 鼠标捕获接口需要代码审计后再拆 ticket。

## 视口左上角 Tips

- 位于视口内容区左上角，避开工具栏、选择操纵器和主要拖放落点；卡片本身不接收场景选择/拖放。
- 默认以短卡片显示当前模式最常用的 3–5 条操作；折叠后只留 `?` 图标。
- 首次进入编辑器默认展开；用户关闭后在当前会话中记住偏好，并可点 `? 视口操作` 重新打开。首轮不写磁盘偏好。
- 展示设备选择：`鼠标`、`触控板`。初始值可跟随系统输入设备，但允许手动切换；自动识别不可靠时默认鼠标并保留明确选择器。
- Edit/Play 切换时同步更换说明。只展示已实现的交互；规划中的 pinch、双击轨道、未来快捷键不出现在 Tips。
- Tips 内容支持本地化，快捷键名按 macOS 显示 `⌥`、`⌘`，其他平台采用对应标识。

## 失败、取消和边界状态

- 视口外按键：不导航、不改选择。
- 右键拖动被 UI 消费：不进入捕获，不移动相机。
- 失去窗口焦点、Esc、模式切换：释放指针捕获并清空按键/修饰键状态。
- F 无有效选择：相机保持不动；首轮暂不显示额外提示。
- 聚焦对象没有有效包围盒：聚焦对象原点并使用安全默认距离，或显示不可聚焦原因；实现时固定一个行为并加测试。
- 键盘事件有焦点的文本框/Project 搜索框优先消费，视口相机不能抢字符输入。
- 拖动资源期间，Project 的拖放捕获高于视口导航；Esc 取消拖放且不改场景。

## 实施顺序与验证

1. 固定事件所有权与输入状态规则：焦点、鼠标捕获、窗口失焦清理、Edit/Play 输入边界。
2. TDD 实现桌面鼠标基线：右键 look/fly、中键 pan、滚轮 dolly、F focus、Option/Alt 轨道。
3. winit 0.30 的 `PinchGesture` 在 macOS 提供 magnify 事件；首轮已接入，但仍需在真实 MacBook/Magic Trackpad 上检查方向和手感。
4. TDD 实现触控板兼容手势与显式 fallback，并在真实 MacBook/Magic Trackpad 上检查副键拖动、自然滚动和捏合。
5. 最后实现 Tips 卡片；根据运行时真实能力筛选内容，检查卡片不拦截选择/拖放。

当前编辑器没有全局 Play 模式，现有 Play/Pause/Stop 控件只控制粒子预览。本轮不新增一个编辑器 Play 模式，也不为它伪造 Tips。每个阶段至少覆盖：视口内外、按下/释放、失焦恢复、UI 消费、无选择 F 聚焦。CI 可验证状态机和路由；触控板手势必须有真实 macOS 手动验证记录，不能由编译通过替代。
