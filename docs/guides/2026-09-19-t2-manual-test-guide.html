T2 · 多光源：人工跑测指南

版本：2026-09-19 · 场景：scenes/23_three_local_lights.ron · 只跑一个场景、一个 launcher。

本次要看什么：画面中应出现三个不同颜色的局部光照区域：左侧偏红、中部偏绿、右侧偏蓝；同时在场景后方能看到三个对应颜色的小球，它们是光源位置标记。这个 T2 验收场景把方向光能量和场景 ambient 设为 0，并用 --no-ibl 隔绝 IBL，避免把局部光照和环境光混在一起。

1. 先跑定向自动验证

在一个终端窗口执行：

cd /Users/ruochenhua/AetherEngine
./scripts/verify-lighting-t2.sh 20260919-t2-manual

打开结果：

open /Users/ruochenhua/AetherEngine/tests/reports/20260919-t2-manual.html

预期 7 个 case 全部为 PASS：

  • 64B GpuLocalLight ABI
  • 红/绿/蓝局部光源提取、稳定排序、32 光源上限
  • 非法 range 被拒绝并包含 lights[i] 路径
  • 三光源 RON 场景解析与 ECS spawn
  • unlit 光源标记材质解析

2. 打开专用场景

如果 release launcher 已经构建过，可直接执行：

target/release/aether-launcher \
  --scene scenes/23_three_local_lights.ron \
  --no-ibl

如果需要先构建：

cargo build -p aether-launcher --release
  1. 只保留这一个 launcher 窗口。
  2. 确认场景中保留一个能量为 0 的方向光兼容实体，以及三个局部 Point light。
  3. 确认场景后方有红、绿、蓝三个小球，分别对应三个 Point light 的位置。
  4. 观察三个接收球体和地面：左边应偏红，中间应偏绿，右边应偏蓝。
  5. 观察中心金属方块：应同时看到三个局部光源产生的彩色高光变化。
  6. 移动相机到不同角度，确认局部光照随距离衰减，而不是整屏统一染色。
  7. 关闭窗口后确认终端返回 shell。

4. 通过标准

检查项通过表现
场景加载不 panic；四个光源都能加载。
颜色左红、中绿、右蓝，颜色能在接收物体上区分开，且三个光源标记保持对应纯色。
距离光照在影响范围内明显，远处平滑衰减。
稳定性窗口关闭后没有残留 launcher。
截图可选 PNG 存在且能打开；不更新 reference。
如果画面没有颜色：不要重跑全部场景。记录是“场景是否打开、是否看到四个光源、画面是否完全灰、截图绝对路径”，然后只反馈这一张截图和终端最后 30 行。
本阶段不验局部光源阴影；阴影属于后续单独的专用场景与专门回归。截图使用 direct-light debug mode 7，不把 IBL 当作局部光照结果。
