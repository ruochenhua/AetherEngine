# Phase 6：高级特性进入评估

## 进入条件

只有满足以下条件才进入高级特性开发：

- Phase 1–3 的验证门禁全部稳定。
- Render Graph 已具备资源版本和有效性语义。
- 有至少一台明确的参考 GPU 和帧时间预算。
- 云、大气、地形和 SSR 的性能数据已经记录。
- 场景切换不会泄漏 GPU 资源。

## 评估顺序

1. 光线追踪阴影：评估是否优于现有阴影且成本可接受。
2. 光线追踪反射：与 SSR/平面反射混合，定义 fallback。
3. 实时 GI：先做离线或低频方案，再评估完全实时方案。
4. 高级体积光和粒子：复用已有体积资源生命周期。

## 评估输出

每个高级特性必须单独提交：

- 技术设计和硬件要求。
- 与现有 Render Graph 的资源/Pass 变化。
- 参考场景和截图基线。
- GPU 时间、显存、带宽数据。
- 关闭特性后的 fallback 路径。
- 明确的“继续 / 暂缓 / 放弃”结论。

## 不接受的进入理由

- 仅因为其他引擎已有该功能。
- 只有截图，没有性能数据。
- 没有资源清理和场景切换策略。
- 没有 CPU 验证或视觉回归路径。
