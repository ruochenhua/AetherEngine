# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records for AetherEngine.

## Naming convention

Files are named `NNNN-title.md` where `NNNN` is a zero-padded sequence number.

## Format

```markdown
# ADR-NNNN: Title

## Status
Proposed / Accepted / Deprecated / Superseded by ADR-NNNN

## Context
What problem are we solving?

## Decision
What did we decide?

## Consequences
What are the trade-offs?
```
