结论：通过。没有引擎/Metal 崩溃；已修复测试自身触发的 Python SIGABRT。

这次报错的根因

fake launcher 测试曾执行 os.kill(os.getpid(), SIGABRT)，这是主动让 Python 子进程崩溃来模拟异常退出。macOS 因此生成了崩溃报告；报告中的 os_kill_impl → os_kill 栈与该代码吻合。

已改为普通的 sys.exit(134)。仍覆盖非零退出，但不会再弹系统 crash reporter。

已完成内容

  • 一个 coordinator 串行执行场景，一次只启动一个 launcher。
  • ready handshake、握手/案例超时、stdout/stderr/launcher.log 记录。
  • 绑定 PID、启动时间、PGID 和 nonce；TERM → KILL 清理子进程组。
  • 取消/退出时统一清理，不创建 Terminal，不启动真实 Metal。
  • 保留现有截图比较、阈值、reference 路径和 HTML 状态语义。
